About:
This website was build for the Stardance Personal Site mission and it includes 3 sections, with links at the top of the page to direct the users to each one. The site is decorated with images found on Pinterest as well as a pixel character made on picrew. 

To set up the website, it is only required to have an index.HTML, style.css and photo files. Paste the code and images into their respective files and doulbe press the index.html file to run the code.
